# 草图模式（Sketch / Hand-drawn）

D2 可以渲染图表，呈现手绘草图的美感。

<div style={{width:'30%'}} dangerouslySetInnerHTML={{__html: require('@site/static/blog/sketch/animated.svg2')}}></div>

- 在 Terrastruct 中，你可以通过手绘模式启用此功能。
- 如果你使用 CLI，可以通过 `--sketch` 标志启用。
- [https://play.d2lang.com](https://play.d2lang.com/?script=qlDQtVOo5AIEAAD__w%3D%3D&sketch=1) 也支持此功能。
