# 组合入门（Intro to Composition）

:::info
本节文档尚不完整。我们将很快补充更多内容。
:::

D2 内置了将多个面板组合成一个图表的机制。

例如，这是一个由 2 个面板组合而成的动画 SVG：

<div className="embedSVG" dangerouslySetInnerHTML={{__html: require('@site/static/img/generated/animated.svg2')}}></div>

在 D2 图表中定义另一个面板的方式是使用 3 个关键字之一。每个关键字声明具有不同继承规则的面板。

| 关键字 | 继承规则 |
|-----------|---------------------------------------------------|
| `layers`（图层） | 不继承任何内容的面板。它们是全新的基础。 |
| `scenarios`（场景） | 从基础层继承的面板。 |
| `steps`（步骤） | 从前一步骤继承的面板。 |

每个关键字服务于不同的用例。上面的示例通过定义一个场景（需要部署热修复的场景）来实现。

到目前为止，我们遇到的所有 D2 图表都是单面板图表，即根面板。

```d2-incomplete
# 根面板
x -> y
```

D2 中的组合是指当你使用上述关键字之一声明另一个面板时。

```d2-incomplete
# 根面板
x -> y
layers: {
  # 名为"numbers"的面板，不从根面板继承任何内容
  numbers: {
    1 -> 2
  }
}
```

所以现在我们有两个面板：root 和 `numbers`。它们当然不能同时可见，因此导出需要适应这些更动态的图表，比如你上面看到的动画 SVG。

组合是 D2 最强大的功能之一，你将在本节中看到各种用例。
