# 导出格式（Export formats）

由于由多个面板组成的图表无法用单个图像表示，因此导出选项有所不同。

- 多个 SVG
  - 默认输出会向输出路径写入多个 SVG 文件。
  - 它们在文件系统上有良好的组织，配有适当的目录和文件名。
  - 内部面板链接会被重写指向这些文件路径，因此打开 SVG 并点击即可工作。
- 单个动画 SVG
  - 适用于小型组合。对于少量步骤或在几个场景之间切换效果很好，但如果组合的面板过多，查看者可能会感到困惑或需要等待循环。
  - 在 CLI 上，传递 `--animate-interval=1200` 会使生成的 SVG 成为动画，每个面板停留 1200ms。
- 单个动画 GIF
  - 与上面相同，但在不同上下文中更有用，例如在不渲染 SVG 的环境中。
- PDF
  - PDF 可以有多页，因此这种媒介适用于多面板图表。每个面板就是另一页，对象可以链接到这些页面。
  - 这目前是图层最合适的媒介。
- PowerPoint
  - 将输出指定为 `.pptx` 即可获得 PowerPoint 演示文稿。
  - 兼容 Google Slides，便于在线共享多面板图表。
