# 图表开发工具

D2 的设计围绕一个目标：**让图表绘制成为工程师的愉快体验**。很多工具声称对于简单图表可以做到这一点，但一旦遇到稍微复杂的图表——那些最需要存在的图表——你就不再有好体验了。

为什么会这样？因为当今大多数图表工具是设计工具，而非开发工具。它们给你一个空白画布和拖放工具栏，就像你在 Figma 或 Photoshop 上看到的那样，并将其预期工作流程视为设计过程。工程师不是视觉设计师，缺乏空间架构系统的能力不应该阻碍有价值文档的创建。每次拖放都不需要规划，更新也不应该是移动元素和调整大小以腾出空间给新内容的令人沮丧的练习。Declarative Diagramming（声明式图表）消除了这种摩擦。

在 Hashicorp 推出 Terraform 让工程师以文本形式编写基础设施之前，他们都是在 AWS 和 Google Cloud 控制台中点击配置基础设施。如今，那已经显得不专业了。审核流程、回滚步骤、历史记录和版本控制在哪里？很难相信全球公司视觉文档的未来将主要由拖放设计工具构成。
